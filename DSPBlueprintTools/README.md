# DSPBlueprintTools 蓝图建筑工具模组

戴森球计划（Dyson Sphere Program）BepInEx 模组，提供蓝图坐标偏移、垂直叠加与线性变换功能，坐标/高度/缩放精确到小数点后 4 位。

## 功能

1. **坐标偏移**：按设定的 X/Y/Z 偏移量（4 位小数）和重复数量，批量偏移蓝图内全部建筑坐标（净偏移 = 偏移量 × 数量）。
2. **垂直叠加**：按设定的层数与每层高度（4 位小数）沿 **Z 轴（高度方向）** 将蓝图叠加为多层，自动检查游戏 15000 建筑上限。
3. **线性变换**：三轴缩放（4 位小数）+ 绕竖直轴任意角度旋转；支持批量替换建筑型号（按物品 ID）。
4. **传送带合并最长化（省带子）**：把蓝图里逐格铺设的同一直线传送带自动合并为最长段。可放置上限随纬度变化（赤道约 1.8、极地约 1.6），模组按蓝图区域纬度自动适配，端点按 0.5 格步进保证可以摆放；也可在配置文件改为固定上限。
5. **产线吞吐量分析**：按配方统计蓝图内机器的产出/消耗速率（每分钟），结合传送带带宽（游戏原型 `beltSpeed`）与分拣器搬运能力，估算供给需要的满带条数，快速定位瓶颈。
6. **剪贴板读取与还原**：直接读取游戏内剪贴板蓝图；蓝图详情窗口旁有"读取"按钮（原生 UI 注入，零每帧开销）；处理结果不自动覆盖剪贴板，确认后再写回，也可一键还原最初读取的原始蓝图。
7. **直接应用**：点"应用/预览"直接替换蓝图粘贴工具中的蓝图，立即摆放。

## 安装

1. 安装 [BepInEx 5](https://thunderstore.io/c/dyson-sphere-program/p/bbepis/BepInEx/) 并至少启动游戏一次。
2. 将 `DSPBlueprintTools.dll` 放入 `BepInEx/plugins/DSPBlueprintTools/`。

## 快捷键

- 默认 `ALT + 4` 打开/关闭工具窗口。
- 可在 `BepInEx/config/dsp.byboy.blueprinttools.cfg` 中修改：

```ini
[通用]
快捷键 = LeftAlt + Alpha4
; 示例：LeftControl + F8、None + F9（无修饰键）
; 键名为 UnityEngine.KeyCode 枚举名
```

## 使用流程

1. 游戏内复制蓝图（或复制蓝图代码字符串）到剪贴板。
2. 按 `ALT + 4` 打开窗口，点"从剪贴板读取蓝图"。
3. 设置偏移/叠加/变换参数后点击对应按钮；确认无误后点"写回剪贴板"（填错了点"还原原始蓝图"）。
4. 切到"产线分析"页签可查看机器产耗速率与带宽供需。
5. 在蓝图粘贴界面直接粘贴，或点"应用/预览"立即使用。

## 构建

```powershell
dotnet build DSPBlueprintTools/DSPBlueprintTools.csproj -c Release
```

引用优先取仓库 `libs/` 目录；如需针对本机游戏版本编译，修改 `.csproj` 中的 `GameDir`。
